| [052 - Cross-Family Agent Session Handoff via a Luna-Compiled Brief](agents/052-cross-family-handoff-brief.md) | A session may leave its pinned adapter family (`model_family`: codex, claude, pi) only by carrying a compacted brief, because adapter-native continuity handles (`cli_session_id`, codex `exec resume`) cannot be read across families and a bare switch would resume cold. Luna compiles the brief from `agent_turns` and bills OpenAI rather than the Claude weekly limit; every decision and constraint carries a `(session_id, seq)` citation plus `commit_sha`, resolved by a `session-recall` tool over the existing Postgres FTS, so the lossy compaction is recoverable rather than permanent. The relaxation is an invariant (a brief is required) rather than a values flag, and compilation is scoped to the handoff direction where the transcript has already crossed to the compiling vendor. Accepted |
| [055 - Tool-Mediated GitHub Access for Agent Principals](agents/055-tool-mediated-github-access.md) | Removes GitHub from the shared, host-matched egress-proxy credential lane for agent principals: agents reach GitHub only through Context Forge MCP tools whose target repo is baked into the tool definition itself, a capability boundary rather than a policy one, gated per Authentik group on both list and call (the tool-tier machinery issue #4569 is already building), with a fine-grained PAT per group behind the tools, scoped to exactly that group's repos and permissions. Two independent enforcement layers, group entitlement and PAT scope, so a Context Forge bug alone cannot reach an out-of-scope repo; an org-wide GitHub App plus a token minter, a per-group App, and a scoped-installation-token App were all rejected because each still needs a minter the PAT-behind-fixed-tools design does not. The design's own cost is that group entitlements and PAT scope must be kept in agreement, mitigated by generating both from one declarative source; states rather than resolves the tension with ADR 020's deferred Context Forge removal, and stays out of scope of ADR 027's merge-authority split. Draft |
| [059 - Authentik Federates MCP Identity; the Monolith Serves MCP Directly](agents/059-authentik-federates-monolith-serves-mcp.md) | Supersedes ADR 020: Context Forge is removed as the MCP entry point and the monolith's own `/mcp` mount, switched to streamable HTTP, becomes the endpoint directly behind Cloudflare. 020's premise that "the gateway adds no auth of its own" is now false (Context Forge verifies authentik tokens itself, refetching the JWKS per call over a Cloudflare hairpin and rebuilding an SSE session and plugin chain per call, 330 to 780 ms per call by its own `duration_ms` logs), but its conclusion holds for a stronger reason: the monolith's `auth/` domain (#4955) already validates the same tokens with a real JWKS cache and already carries the delegation model (#4940) this codebase is building toward, so removal deletes the buggy verifier rather than patching it. Outstanding: authentik DCR advertised on the provider (verified live: no `registration_endpoint`, duplicate `openid` scope), role-shaped workload scopes (#4940), RFC 9728 protected-resource metadata served by the monolith, and the deterministic tool rename 020 already specified. Resolves ADR 055's stated tension toward #4946 (the monolith's own GitHub mutation broker) and marks 055 superseded. Draft |

| [010 - Bazel Skyframe Snapshot as a Stateless Query Demo](embervm/010-bazel-skyframe-snapshot-query-demo.md) | A public `/ember` demo proving Skyframe efficiency: Bazel's loading+analysis graph lives in a local, single-server JVM heap that RBE cannot cache (RBE caches execution only), so a cold server re-pays full analysis (Abseil 13.8s, a monorepo minutes) before RBE is ever consulted; Skycache is Blaze-internal with no OSS backend. Snapshot the warm server as a base and serve each request from a disposable copy-on-write clone that runs one read-only `bazel cquery` then reaps, so the lifecycle is request-response-reap with zero persisted state and RBE kept as-is (recorded) for execution. Interactive tier Abseil (~0.6GB base, ~200MB heap, zero-egress, expression-only input), headline/scale tier Envoy (multi-GB heap) measured on Linux. Reuses ADR 003/009 snapshot artifacts and R7 copy-not-rebuild relight; no new node verbs. Silent-failure guards: snapshot after the warming client exits, serving flags must equal warming flags or the analysis cache is discarded. Draft |
