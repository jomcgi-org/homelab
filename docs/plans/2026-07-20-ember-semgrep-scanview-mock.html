Numbers and build notes

The cold lane needs one honest measurement: force a cold-path scan (fc-invoke has the fallback) and pin boot / rule-load / scan segment durations from it. ~8 s is the estimate from known pieces (7.6 s boot-and-warm measured on this hardware, ~0.7 s rule load, match time). The savings counter then re-baselines from 11 s vendor-median to our own measured cold time, which makes it fully checkable. Code shape: one ScanView component owns editor, gutter, sweep, finding pins, receipt, and race; the page composes it with the session/Turnstile shell. The race runs once per page visit (replays on demand, never loops).
