For a legacy issue, `projects/factory/connector/itsaplan/ops/recover-creation-snapshot.sh` derives the same hashes from the original insert tuple in a physical restore and fills the empty creation payload. The command requires the issue ID and the insert transaction ID from archived WAL. `check_legacy_recovery` in `projects/factory/tests/itsaplan/integration_test.py` verifies the recovered payload against the original values after a description edit and verifies that a second invocation produces the same result. Production restore availability is an activation prerequisite.
