The factory chart adds an init container that patches the pinned itsaplan issue service and mounts that source file into the API container. The service records title and description hashes in the same transaction that inserts the issue. For a legacy issue, `projects/factory/connector/itsaplan/ops/recover-creation-snapshot.sh` derives the same hashes from the original insert tuple in a physical restore and fills the empty creation payload. The command requires the issue ID and the insert transaction ID from archived WAL.
