# Home cluster root

This directory is the generated Kustomize root for project Applications aimed
at the home cluster.

[`kustomization.yaml`](kustomization.yaml) is generated by
[`bazel/images/generate-home-cluster.sh`](../../bazel/images/generate-home-cluster.sh).
The checked-in file currently includes these repository roots:

- `projects/inference/deploy`
- `projects/monolith-agents/deploy`
- `projects/operators/oci-model-cache/deploy`
- `projects/platform`

The generator discovers project `deploy/kustomization.yaml` files and project
aggregators. Its explicit exclusion list omits the GKE roots and application
domains already removed from the home composition. Edit the project source or
the generator, then regenerate this file. Direct edits to the generated
Kustomization will be replaced by the next format pass.

This directory records desired GitOps input. It does not establish what a live
cluster currently runs. Cluster placement and migration status are documented
from repository evidence in [`../platform/ARCHITECTURE.md`](../platform/ARCHITECTURE.md)
and [`../../docs/security.md`](../../docs/security.md).
