## Emitted JavaScript baseline

The local public-only Vite build used source commit
`1f536d94934ccfef73aa3a2129f00be60f8a44ca` on 14 November 2026. Private
routes, friends routes and `src/lib/private` were excluded, matching
`:src_public`. These values match the baseline in
`performance/BUNDLE_BUDGETS.md` (PR #7969). The deployed revision was not
verified.

Initial JavaScript includes the runtime, router, layouts, page and static
imports, counted once per route. Deferred JavaScript follows only that
route's dynamic imports and excludes the router's imports of other pages.
Each file is independently compressed with gzip level 9. External worker
assets are separate. Values below are exact bytes.

`/app/frank` serves a static document with inline scripts, measured at 10,080
gzip bytes for the whole document. It has no separate Svelte JavaScript
closure. `/app/firecracker` redirects; the table records its emitted page
closure and its destination separately. A redirect navigation does not
download the source page's closure.

These artifact sizes do not establish browser wire transfer. All browser
transfer and timing fields above remain unmeasured. The JavaScript closures
exclude HTML, inline data, CSS, fonts, images, tiles and API responses.
Grimoire's admission-gated corpus was not fetched to measure its bundles.
Trips uses MapLibre's default worker, so zero separate worker bytes does not
mean that no worker runs. Generated version strings and chunk names caused
7 to 16 gzip bytes of variation in the budget-only rebuild.
