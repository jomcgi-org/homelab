Explainer

Follow a read request

Every read goes through the same six stages. The query API decides who may see which columns before a single row leaves storage.

6 stages p50 38 ms

The path

Each stage can stop the request.

  1. Request

    The client sends SQL with its token.

  2. Access

    ACLs pick the tables and columns this caller may read.

  3. Read

    DataFusion scans only the allowed columns in Iceberg.

  4. Mask

    Sensitive values, such as email, are masked by policy.

  5. Log

    Lineage records who read what, and why.

  6. Return

    Arrow batches stream back to the caller.

Who sees what

The same query returns different columns per role.

Role Name Email Balance
Admin shown shown shown
Analyst shown masked shown
Support shown shown denied

Try it

The same request from a terminal.

curl -H "Authorization: Bearer $TOKEN" \
  -d "SELECT name, email FROM customers LIMIT 3" \
  https://query.example/v1/sql
